# AI MoneyGuard Website

A responsive static marketing website for AI MoneyGuard, designed for GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — complete responsive design
- `script.js` — mobile navigation + scroll reveal animation

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `AI-MoneyGuard-Website`).
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the public website URL.

## Custom domain
After the GitHub Pages site works, add your domain under **Settings → Pages → Custom domain** and follow GitHub's DNS instructions.
